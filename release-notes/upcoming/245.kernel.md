`np.searchsorted` on a sorted `int64` array is served by a kernel, on either side, for `int64` needles: an array of them, one `np.int64` or a Python int. On x86-64 (Intel Core i5-14600KF) a call with one needle is about 2.1x faster than NumPy at any length, and one with 4,096 needles against 4,096 elements about 3.3x. Needles of another type, such as `int32` or a float, go to NumPy as before.
