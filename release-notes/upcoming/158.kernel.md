`np.hypot` on `float64` is served by a kernel on x86-64 Linux where the C library computes `hypot` the way glibc 2.35 and later do, which `install()` checks on your machine before using it: about 4.7x faster than NumPy at 4,096 elements and 6.8x at a million, measured on x86-64. Where the C library differs, or the data overflow or underflow, `np.hypot` stays NumPy's.
