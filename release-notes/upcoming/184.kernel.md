`np.hypot` on `float64` is also served by a kernel on Apple Silicon Macs where macOS's `hypot` computes it the way the kernel does, as on macOS 27.2, which `install()` checks on your machine before using it: about 4.2x faster than NumPy at 4,096 elements and 4.7x at a million, measured on an Apple M1 Pro. On another macOS whose `hypot` differs, `np.hypot` stays NumPy's.
